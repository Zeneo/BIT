BIT Labaratoriniai darbai
Labaratoriniams darbams pradėti reikia:

BIT Labaratoriniai man patika

Būti susidiegus GIT'ą
Turėti GitHub prieigą (kurią jeigu čia skaitot jeu turit :D).
Būti susitvarkius SSH raktus naudojamame kompiuteryje (jeigu nesate žiūrėkite į skiltį "SSH raktų įdiegimas")
Jeigu viskas sutvarkyta ir paruošta reikia įgyvendinti šiuos žingsnius:

Nueiti į savo localhost direktoriją ar kur jūs norėsite talpinti failus
Joje įėjus spausti dešnį pėlės klavišą ir pasirinkti "git bash" (arba per terminalą nueiti iki tos direktorijos)
Tada terminale įvesti: git clone git@github.com:Zeneo/BIT.git
Parsiklonavus įeiti į BIT direktoriją su komanda "cd BIT"
Joje paleisti komandą "git branch {vardas}_{pavarde}" (TIK LOTYNIŠKOS RAIDĖS BE "ĄČĘĖĮŠŲŪŽ" AR PAN.!!!)
Įvykdykite komandą "git checkout {vardas}_{pavarde}"
Įvykdykite komandą "git commit -a -m 'Mano pirmas commit' "
Įvykdykite komandą "git push --set-upstream origin {vardas}_{pavarde}"
Jūsų brancho pavadinimas - {jūsų vardas}_{jūsų pavardė} GIT repozitorija bus viena, prisidės tik nauji katalogai su naujais labaratoriniais.
