Labaratoriniai darbai

Labaratoriniams darbams pradėti reikia:
1. Būti susidiegus GIT'ą 
2. Turėti GitHub prieigą (kurią jeigu čia skaitot jeu turit :D). 
3. Būti susitvarkius SSH raktus naudojamame kompiuteryje (jeigu nesate žiūrėkite į skiltį "SSH raktų įdiegimas")

Jeigu viskas sutvarkyta ir paruošta reikia įgyvendinti šiuos žingsnius:
1) Nueiti į savo localhost direktoriją ar kur jūs norėsite talpinti failus
2) Joje įėjus spausti dešnį pėlės klavišą ir pasirinkti "git bash" (arba per terminalą nueiti iki tos direktorijos)
3) Tada terminale įvesti: git clone git@github.com:Zeneo/BIT.git
4) Parsiklonavus įeiti į BIT direktoriją su komanda "cd BIT"
5) Joje paleisti komandą "git branch {vardas}_{pavarde}" (TIK LOTYNIŠKOS RAIDĖS BE "ĄČĘĖĮŠŲŪŽ" AR PAN.!!!)
6) Įvykdykite komandą "git checkout {vardas}_{pavarde}"
7) Įvykdykite komandą "git commit -a -m 'Mano pirmas commit' "
8) Įvykdykite komandą "git push --set-upstream origin {vardas}_{pavarde}"


Jūsų brancho pavadinimas - {jūsų vardas}_{jūsų pavardė}
